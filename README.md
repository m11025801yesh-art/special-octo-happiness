# 千川研习社

给教育类目创作者使用的中文个人工作台。将产品事实、用户评论、参考视频、脚本与投放数据放在一起，让每次创作都能回到原始依据。

已预填用户提供的「考点模型精讲练」资料：当前售价 9.9 元，纯虚拟交付，包含 200 个动态模型、9 节直播公开课、五科约 5000 分钟视频、1 对 1 学情诊断与规划、28 天规划营。旧文档里的价格、实物书与未核实承诺不作为当前权益。

## 不懂编程，怎么打开

使用交付的“千川研习社-直开版与20条脚本.zip”，先解压，再用电脑的 Chrome 或 Edge 打开“千川研习社-双击打开.html”。不要在聊天软件的附件预览窗口中运行。这个版本将页面和业务功能打包在一个文件里，不需要 Node.js、GitHub 或服务器。

页面内置本次对话 Agent 创作的 **20 条完整脚本：A 线 7 条、B 线 7 条、C 线 6 条，共 100 个分镜**。可直接阅读、筛选、编辑和导出，无需模型密钥。每条附有产品资料来源、受众假设、素材要求和对照测试建议；没有把这些创意伪装成真实评论统计或已投放的爆款。

另有 Word 和 Excel 成稿，方便拍摄和排期。当前云环境的受管理 Chromium 禁止 `file://` 导航，因此直开包使用“只提供同一静态文件、没有后台 API、加载后断网”的浏览器流程验证；没有绕过浏览器策略，也未声称在该云浏览器中验证了双击入口。普通电脑浏览器的具体设置仍可能影响文件打开和存储。

**直开版的数据保存在当前浏览器**，与云服务数据分别保存；请使用同一浏览器打开同一路径的文件，并定期导出备份。密钥只在当前网页内存中，刷新后需重新填写。新增 AI 生成需要联网，浏览器直连服务商仍可能受跨域、地区和账号权限影响。手机附件预览器不一定运行网页脚本；已将静态网页文件同步到仓库的 `gh-pages` 分支；当前环境不能确认 GitHub Pages 是否已启用或公网是否可访问。

## 怎么使用

### 简洁创作（默认入口）

默认打开 **开始创作**，只需要填写 **产品、需求、爆款参考** 三个文本框，然后点击 **开始创作**。产品可整段粘贴；受众、数量、时长、语气、重点和结尾要求直接写在需求里，不再要求先导评论、归类主题、选择创作线或创建研究计划。没指定数量时先写 1 条，每批上限 20 条。参考内容可为空，有参考时粘贴逐字稿或镜头说明；仅有链接时提示补充内容，不声称已读取原视频。多条参考文案用单独一行 `---` 分隔；普通空行保留为同一视频的段落。

Agent 自动执行：理解产品 → 评论语义归类与频次 → 跨类目参考视频拆解与结构频次 → 痛点与产品/竞品演示对应 → 逐条选题与创作 → 目标用户审阅。审阅未通过时，先回溯痛点、产品机制、演示与参考结构，再修改并审阅当前稿，最多三轮。产品不具备对应能力时暂停并列出需要补充的资料；三轮后仍有疑虑时保留问题，不标成通过。自检属于模型模拟，实际成交需要投放验证。

主页面的 **补充调研资料（选填）** 可录入评论、视频文案/链接和竞品。新任务冻结最近 250 条评论、最多 5 条有文案的视频（本次粘贴优先，按文案去重）和最近 10 份竞品资料。频次由程序根据实际样本计算并降序展示：主题按关联评论数，关键词按包含原词的评论数，完整结构按视频数；不把频次等同有效性。没有评论或表现证据时分别标明需求假设、未验证爆款。已有任务不受后来修改影响，补材料后新建任务。

结果默认展示可复制口播、用户视角判断及缺口；研究统计、原声、参考引文、结构与语言分析、产品对应、竞品启发、分镜和修改过程折叠查看。每次模型调用成功后独立保存；中断从未完成步骤继续。20 条脚本的策略逐条生成，避免一次响应塞入全部研究报告。页面关闭后不会自动继续。研究与创作按所选模型服务商计费：一批最多 `8 + 12 × 脚本数` 次调用（满 5 条参考、满三轮修改的上界），失败重试另计；实际无素材或提前通过时更少。输入随任务保存，不覆盖产品档案。

简洁创作的成稿点击 **录入投放数据**，填写 CTR、CVR、3 秒留存等及可比基准，保存后自动关联原稿与复盘，研究并生成下一版本。只调整一个主要变量以便对照，不把指标关联当成因果；旧稿、旧数据和修改记录保留。缺模型连接时保存任务，连接后继续。仍可从“数据复盘”点击“据此迭代”恢复这条路径。

当前没有平台自动搜索、评论/直播采集或自动读取视频链接；考古家、蝉妈妈、抖音、小红书资料仍需导入。新流程提供的是对已提供素材的研究与迭代，不会把待补调研伪装成已完成的外部搜索。

### 更多工具与资料录入

需要细致管理时，点击 **更多工具 → 资料录入**，仍可使用三个独立入口：

- **手动输入产品资料**：编辑产品档案，支持整段粘贴原始介绍、保存产品来源 / 购买页链接；产品名、价格、交付和卖点仍可分别核对。
- **添加爆款 / 参考视频**：手动保存逐字稿、镜头笔记、来源和表现数据。未提供可核验表现数据时，仅视为参考视频。
- **粘贴视频链接**：支持网址或包含网址的平台分享文字。可先仅收藏链接，显示“待补文案”，随后原地补充逐字稿；相同链接的快速收藏会去重。

链接不会自动下载、转写或读取视频内容；只有链接时不能用于 AI 视频分析或 Agent 视频任务。已有逐字稿的素材可以编辑，编辑会清除旧 AI 拆解；已经被脚本或任务引用的素材不覆盖，需新增记录以保留原始依据。

### Agent 任务（自动串联研究与创作）

在左侧进入 **Agent 任务**：填写本批数量（1–20 条）、A/B/C 主线、时长与创作要求，可选择最多 5 条参考视频。点击“生成任务计划”只保存计划；点击“启动任务”才开始调用已配置的模型。

流程为：评论语义归类 → 所选视频拆解 → 产品能力与证据匹配 → 按频次及适配程度安排选题 → 逐条创作、用户视角自检、按需修订。选择 20 条且 A/B/C 均衡时，安排 A7/B7/C6。选题必须不同；高频只表示本任务样本中的出现频次，无法支持的产品能力不会强行写成卖点。

每个任务冻结创建时的产品、最近最多 250 条评论、所选视频与竞品资料；研究结论在任务详情查看，不覆盖其他手工研究。补充新素材后建立新任务。需要真实评论才能建立任务，没有视频时不生成“爆款结构”推断。模型密钥可稍后配置，但必须配置后才能执行。

每一步独立保存，限流、失败或刷新后可以从未完成步骤续跑。已完成步骤有重复请求保护，已保存成稿不会再次生成。可在当前步骤完成后暂停；关闭页面不会自动执行余下任务，直开版刷新后还需重新填写密钥。每条最多三次模型调用（初稿、自检、可选修订），首轮调用上限为 `3 + 所选视频数 + 3 × 脚本数`；重试可能产生额外费用，保存失败或响应丢失时不能保证服务商未计费。

任务成稿仍可编辑、录入投放数据并按原任务资料迭代。所有素材引用限制在本次实际提供给模型的范围内。任务引用的评论和视频会保留以便核验；当前最多保留 20 个任务。模型研究和自检结果是待验证判断，不能保证提分或成交。

### 分步操作

1. **产品档案**：查看和修改产品名、权益、售价、A/B/C 三条卖点线，以及证据和适用边界。当前购买跳转方式仍待确认。
2. **用户洞察**：粘贴真实评论，每行一条；或导入 UTF-8 CSV/JSON。系统先去重，再按规则、人工或 AI 整理主题。点击「看原声」核验频次。
3. **爆款研究**：保存参考视频逐字稿、镜头笔记、链接与可核验的表现数据。人工填写结构或用 AI 拆解。没有表现数据的视频仅作为参考，不认定为已验证爆款。
4. **痛点与产品**：记录产品如何解决问题、如何拍出来、还缺什么证据。可以加入竞品资料并重新分析。
5. **脚本工作室**：选择 A/B/C 线、痛点、参考视频与时长，生成、改写或迭代。AI 流程包括初稿、用户视角自检、按需修订一次。所有修改保留版本。没有 AI 时可使用带明确占位提示的规则骨架。
6. **数据复盘**：选择脚本版本，填写 CTR/CVR/3 秒留存/完播率或原始计数，输入可比的对照指标。系统提出分段假设和单变量测试建议，可据此创建新脚本版本。
7. **AI 连接**：支持 DeepSeek、OpenAI、通义千问。选择自己的服务商，填写模型和 API 密钥并测试。密钥无需发给开发者或聊天助手。

默认没有任何真实评论、爆款视频或投放数据，不会自动造出大盘统计。统计只代表用户导入的样本。AI 模型会按服务商规则计费；点击创作、继续、AI 分析，或保存简洁脚本投放数据并迭代时，才会向所选模型发送所需素材。

### 导入格式

CSV 表头可用英文 `text,source,url,audience`，或中文 `评论,来源,链接,人群`。引号、逗号、换行通过 Papa Parse 处理。单次最多 1000 条、2 MB，工作台评论上限 10000 条。

JSON 为数组，例如：

```json
[
  {"text":"这里填真实评论", "source":"平台与话题", "url":"https://example.com/source", "audience":"高一家长"}
]
```

规则/AI 重新归类会重建当前主题，产品对应分析会随产品或研究素材变化失效。脚本保留创作时产品快照；已经被脚本引用的评论或视频不能删除。

### 数据口径

- 主题频次按关联评论的唯一 ID 计算；同一评论可匹配多个主题，占比合计可超过 100%。文字规范化后完全重复的评论只计一次，不等于独立用户数。
- AI 主题整理一次只分析最近 250 条，其他未归类评论仍可见。视频结构按完整结构名称匹配；同义结构尚未自动合并。
- CTR = 点击 / 曝光；CVR = 成交 / 点击；3 秒留存 = 达到 3 秒播放 / 总播放；完播率 = 完整播放 / 总播放。百分比填 `3.5` 表示 `3.5%`。
- 默认计数应为统一周期与去重口径。若平台事件定义不同，需要先统一定义再填入。分母为零不显示伪造的 0% 指标。没有基准时不臆造“行业合格线”。

## 启动与开发

需要 **Node.js 24+**。生产依赖只有锁定版本的 Papa Parse。

```sh
cd /workspace/special-octo-happiness
npm ci --cache /tmp/qianchuan-npm-cache --no-audit --no-fund
npm start
```

默认监听 `127.0.0.1:3000`。`npm start` 开启 Node 对环境代理的支持，继续使用 TLS 证书验证。`PORT`、`HOST`、`DATA_DIR` 可以设置端口、监听地址和数据目录。当前为个人开发版本，没有账号体系；公开部署前需要增加访问认证与 HTTPS。静态版已同步到 `gh-pages` 分支，公网 Pages 可访问性尚未确认。

`npm run dev` 用于开发自动重启。首次启动从 `config/product-profile.json` 预填产品资料；已有工作台文件始终优先，不覆盖用户修改。

云服务与直开版复用 `lib/workspace.mjs`，模型与领域逻辑共用。`config/script-catalog.mjs` 保存 20 条人工审阅的 Agent 脚本源稿，`lib/catalog.mjs` 将其转成工作台脚本版本；稳定 ID 保证不会反复添加或覆盖用户已有修改。测试可用 `QIANCHUAN_NO_CATALOG=1` 禁用服务端内置脚本，以隔离测试样本。

重新构建直开包：

```sh
npm run build:standalone
```

重建 Word、Excel 和 Markdown 成稿（仅导出工具需要 Python 依赖）：

```sh
python3 -m pip install -r requirements-export.txt
node scripts/export-script-data.mjs
python3 scripts/export-script-documents.py
```

输出在 `dist/`，该目录不提交 Git。核心脚本源稿与构建、导出代码会提交。

资料保存到 `.data/workspace.json`，写入使用临时文件加重命名。该目录被 Git 忽略。页面可导出全部资料及单条 Markdown 脚本、CSV 评论。服务重启保留数据，浏览器清缓存不会删除工作台数据。当前只支持单进程运行；没有跨实例共享或多用户隔离。

### AI 凭据与联网

可以在界面输入 API 密钥，只在服务进程内存中保留。服务重启后需要再次输入；不会写入磁盘、浏览器存储或导出文件。也可以安全地在环境设置配置：

```text
QIANCHUAN_AI_KEY=<通过环境设置注入，不写在仓库中>
QIANCHUAN_AI_PROVIDER=openai
```

新工作台默认选择 OpenAI / `gpt-4.1-mini`，已有配置保留。连接入口支持 `?provider=openai#settings`，预选 OpenAI，点击保存后生效。OpenAI API 按 API 账户单独计费，不包含在 ChatGPT 订阅中。

`QIANCHUAN_AI_PROVIDER` 可为 `deepseek`、`openai`、`qwen`。服务器上的通用环境密钥为兼容旧配置，未填写服务商时仍按 DeepSeek 处理；使用 OpenAI 环境密钥必须显式设置 `QIANCHUAN_AI_PROVIDER=openai`。前端选择的服务商必须与环境密钥提供商匹配。密钥值不会通过状态接口返回。三个服务对应的 HTTPS 目的域名分别是：

- DeepSeek：`api.deepseek.com`
- OpenAI：`api.openai.com`
- 通义千问：`dashscope.aliyuncs.com`

设置环境网络允许域名与密钥后，必须点「测试连接」实际验证。当前开发验证未调用真实付费模型；模型适配、JSON 校验和最多三次调用的生成流程使用模拟返回测试通过，不能视为真实模型效果验收。


浏览器完整流程测试使用隔离的临时数据，不修改实际产品工作台：

## 当前边界与后续接入

- 按用户选定的第一版，平台素材均为手动导入，未接入考古加、蝉妈妈、抖音或小红书的自动搜索、评论采集或直播采集。
- 参考视频依据逐字稿与镜头笔记分析，尚未实现视频上传、语音转写和视觉识别。链接只记录来源。
- AI 对应关系、爆款原因与复盘诊断是待验证的研究判断；不能保证购买、提分或投放表现。简洁创作最多自动修改三轮并逐轮复核；旧分步脚本工具最多一轮。后续迭代由新材料、人工反馈或真实投放驱动。
- 开源项目取舍与许可证见 [docs/open-source-research.md](docs/open-source-research.md)。产品文档差异见 [docs/product-decisions.md](docs/product-decisions.md)。
