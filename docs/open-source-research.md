# 开源项目核查与复用

核查日期：2026-10-11。尝试 GitHub 搜索 API 时，当前网络代理返回 403，因此没有声称完成全网排名或穷尽搜索。随后通过平台已有 HTTPS Git 代理，只读获取下列项目 README 和 LICENSE，评估可复用性。

| 项目 | 适配点 | 许可证与本次决定 |
| --- | --- | --- |
| [Dify](https://github.com/langgenius/dify) | 可视化工作流、知识资料、模型连接与调试 | Dify 自定义开源许可证，基于 Apache 2.0 且包含多租户、前端标识等附加条件。需要多组件部署。本次未复制或集成代码；适合后续确有复杂工作流管理需求时评估。 |
| [LangGraph](https://github.com/langchain-ai/langgraph) | 有状态工作流、可恢复执行、人工介入 | MIT。适合后续多步骤长任务、断点恢复和并行研究。当前流程只需生成、自检、一次修订，使用直接模型调用即可；本次未复制代码，也未引入额外框架依赖。 |
| [Papa Parse](https://github.com/mholt/PapaParse) | CSV 表格、引号、逗号、多行中文评论解析与导出 | MIT。实际采用 `papaparse@5.5.3`，锁定版本并保留包内许可证。直接用于浏览器评论导入与 CSV 导出；导出启用公式转义。 |

没有把平台采集工具声称为已接入的数据源。用户选择第一版手动导入；后续自动搜索应先核实平台的可用接口、权限与数据字段，再替换对应的素材入口。

测试覆盖多行和引号 CSV、脚本来源 ID 校验、指标分母、历史版本、模型出错与最多三次调用的迭代流程。开源库的使用不代替业务效果验证。
