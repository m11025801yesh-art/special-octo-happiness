千川研习社 · 双击打开版

电脑打开方法（无需编程）
1. 下载“千川研习社-直开版与20条脚本.zip”，解压到一个固定文件夹。
2. 双击里面的“千川研习社-双击打开.html”。
3. 如果系统问用什么打开，选择 Chrome（谷歌浏览器）或 Edge（微软浏览器）。

也可以直接下载单个 HTML 文件，保存到电脑后再双击。
请不要在聊天软件的文件预览窗口中运行；先下载到电脑。

它是一份可以在电脑浏览器中直接使用的网页，不需要启动服务器。
产品资料已按你提供的 9.9 元虚拟产品和 A / B / C 三条线预填。
打开后默认进入“资料录入”，可手动填写产品、添加视频资料、粘贴视频链接。
产品原文可整段粘贴；视频可先收藏链接，再从“待补文案”入口补充逐字稿。
点击“查看 20 条脚本及后续版本”或左侧“脚本工作室”，可看到本次对话 Agent 写好的 20 条完整脚本：A 线 7 条、B 线 7 条、C 线 6 条。
每条约 55 秒，包含完整口播、画面、字幕、来源依据和投放测试建议；可按 A/B/C 筛选。
阅读、修改这 20 条脚本不需要配置 AI 密钥。Word 和 Excel 文件也可以单独打开使用。
评论导入、频次统计、人工匹配、脚本骨架、版本管理和投放复盘无需联网。

资料保存在哪里
资料保存在当前浏览器的本机存储中，和云环境中的工作台分别保存。
请尽量用同一浏览器打开同一路径下的 HTML 文件。
不要使用无痕窗口；不要随意清除浏览器数据。
定期点击“导出工作台”保存 JSON 备份。修改文件位置或浏览器不会自动迁移资料。
首次下载不包含任何密钥，也不包含虚构的评论或投放数据。
内置脚本来自产品资料创作，其受众问题是待验证假设，不代表真实大盘频次或成交效果。

AI 怎么使用
进入“AI 连接”，选择你有账号的服务商，填写自己的 API 密钥，保存并测试。
这部分需要联网，并按服务商规则计费。
下载版直接由你的浏览器连接所选服务商；服务商的地区和跨域限制可能导致连接失败。
密钥仅保留在当前网页内存中，不写进浏览器存储或导出文件，刷新或关闭后要重新填写。
当前并未使用真实付费密钥验证服务商连接，不能保证所有网络环境都能连接。
无需向聊天助手发送密钥。

Agent 自动任务
1. 在“用户洞察”粘贴真实评论；参考视频可在“爆款研究”录入逐字稿。
2. 进入“Agent 任务”，选择 1–20 条、A/B/C 主线与时长，可选最多 5 条视频。
3. 点击“生成任务计划”：仅保存计划，不调用模型。
4. 配置并测试 AI 后点击“启动任务”：自动归类、拆解、匹配、选题、创作、自检。
5. 每一步完成后保存，可暂停或在失败后继续；任务详情可查看频次、原声、缺口和成稿。
任务使用创建时的资料快照，补充新资料后请新建任务。关闭页面不会自动跑完剩余步骤。
生成 20 条且均衡选择时为 A7/B7/C6。首轮最多调用模型 63 次，加每条参考视频 1 次；重试另计。
没有真实评论或密钥时不会假装执行成功；已有 20 条资料成稿仍可直接阅读。
